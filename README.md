# 🛡️ CompTIA Security+ (SY0-701) – Student Notes
This repository contains **student-friendly study notes** for the  
**CompTIA Security+ (SY0-701 / V7)** certification.

The notes are aligned with the **official exam objectives** and focus on explaining core cybersecurity concepts in a clear and simple way.

---

## 📘 Exam Information
- Certification: CompTIA Security+
- Exam Code: SY0-701 (V7)
- Level: Entry-Level / Foundational Cybersecurity
- Target Audience: Students, beginners, and junior security roles

---

## 📚 Exam Domains Overview

### 🔹 General Security Concepts (12%)
Covers the foundational ideas every security professional must understand:
- Security controls (preventive, detective, corrective, managerial, technical)
- Core principles: CIA Triad, AAA, non-repudiation
- Zero Trust concepts
- Basic change management
- Cryptographic fundamentals (encryption, hashing, PKI, digital signatures)

---

### 🔹 Threats, Vulnerabilities, and Mitigations (22%)
Focuses on understanding how attacks happen and how to reduce risk:
- Threat actors and their motivations
- Common attack vectors and attack surfaces
- System, application, and cloud vulnerabilities
- Malware and password-based attacks
- Basic mitigation techniques such as hardening, segmentation, and patching

---

### 🔹 Security Architecture (18%)
Explains how secure systems are designed and structured:
- Architecture models (on-prem, cloud, virtualization, IoT, ICS)
- Secure enterprise infrastructure concepts
- Data protection and classification basics
- High availability, backups, and business continuity fundamentals

---

### 🔹 Security Operations (28%)
The largest domain, focused on day-to-day security activities:
- Secure configuration and system hardening
- Asset and vulnerability management
- Monitoring, logging, and alerting
- Enterprise security tools (Firewall, IDS/IPS, NAC, DLP, EDR/XDR)
- Identity and Access Management (IAM, SSO, MFA)
- Incident response basics and digital forensics concepts

---

### 🔹 Security Program Management and Oversight (20%)
Covers governance, risk, and organizational security:
- Security policies, standards, and procedures
- Risk management and Business Impact Analysis (BIA)
- Third-party and vendor risk
- Compliance and privacy concepts
- Audits, assessments, and security awareness training
